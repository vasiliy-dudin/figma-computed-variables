Computed Variables

A Figma plugin for design systems that need expression-based tokens. Tokens are defined in JSON with math, color modifier functions, and alias references. The plugin evaluates them and writes the computed values to Figma Variables.

Install on Figma View on GitHub

The problem

Figma Variables support two things: a static value and an alias pointing to another variable. They don't support computed values.

In a large design system, token relationships are the architecture. A hover color is the primary color lightened by 12%. A ghost button background is the brand color at 18% opacity. Button padding is always twice the base spacing unit. Semantic surface tokens alias foundation colors that may themselves be defined in oklch.

Without expression support, every derived value must be calculated manually and hardcoded. When a base token changes, dozens of variables need updating by hand. The relationship between tokens exists only outside Figma.

How it works

Define tokens in JSON. Use expressions where needed:

{
	"semantic": {
		"button": {
			"bg": {
				"$type":  "color",
				"$value": "{color.primary}"
			},   // → native Figma alias
			"bg-hover": {
				"$type":  "color",
				"$value": lighten("{color.primary}", 12%)
			}, // → computed static value
			"bg-ghost": {
				"$type":  "color",
				"$value": alpha("{color.primary}", 18%)
			}, // → computed static value
			"padding": {
				"$type":  "number",
				"$value": "{spacing.base} * 2"
			}      // → computed static value
		}
	}
}

Click Apply. The plugin evaluates each expression and writes the result to the corresponding Figma Variable. A pure alias reference becomes a native Figma alias and stays reactive. Expressions with math or color functions produce a computed static value — written in oklch, which Figma Variables natively support.
